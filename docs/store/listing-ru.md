## Название

**RagRogue**

## Краткое описание (из спеки)

Ходи сам — бей авто. Roguelike в духе Ragnarok.

## Полное описание (черновик)

**Что это.** RagRogue — midcore-данжен RPG для телефона: процедурные этажи, фэнтези-бой и навыки в духе классических MMORPG. Управление одно: вы ходите сами, а удары и умения стреляют автоматически.

**Как играть.** В хабе выбираете героя, надеваете снаряжение и входите в подземелье. На этаже двигаетесь виртуальным стиком (альбомная ориентация). Когда враг в радиусе, автобой сам бьёт и кастует навыки по кулдауну. Смысл игры — позиционирование: кайт, узкие проходы, держать мага и лучника на дистанции.

**Три класса.** Три отдельных слота героев:

- Мечник — ближний бой, держит линию.
- Маг — область и взрыв, лицо бренда на иконке.
- Лучник — одиночные цели и кайт.

**Прогресс остаётся.** Уровень и экипировка (оружие, броня, аксессуар; редкости N / R / SR) сохраняются между забегами. Умения класса открываются с уровнем. Временные усиления забега сгорают при смерти.

**Короткие офлайн-забеги.** Цель сессии — 3–5 минут: несколько комнат на этаже, затем босс акта. Сеть для ядра игры не нужна. Облачного сейва и аккаунта в MVP нет.

**Монетизация (TBD).** Модель ещё не утверждена (реклама / IAP / гибрид, отношение к pay-to-win). В MVP нет платных систем. Когда решение будет принято, этот абзац заменят честным описанием того, что реально есть в билде.

## Заметки для ревьюера

- Логина нет: прогресс только локально на устройстве.
- Туториал в MVP: хаб → выбрать класс → экипировать → войти в данж; бой начинается при сближении с врагом.
- Бой автоматический; игрок двигает героя стиком.
- Скриншоты должны совпадать с альбомным геймплеем (не портрет).

## IP и формулировки

Формулировка «в духе Ragnarok» в кратком описании — из спеки. Допустимость в официальном RU-листинге **на проверке у юриста**. Если нельзя — убрать товарный знак и описать фэнтези без названия Ragnarok. Не использовать официальные логотипы, спрайты и имена Gravity / Ragnarok.
